# MEMBRETES — Catálogo de chyrons reutilizables

> Plantilla central de membretes (lower-thirds) para los vídeos foresight.
> Cada entrada: identificador corto + texto del membrete (1 línea) + URL de la fuente + notas de uso.
> Norma editorial: formato `*fuente · serie/informe · año*`. Misma fuente puede aparecer varias veces si cambia el año o el subinforme.

## Cómo usar este archivo

- Para cada dato del guion, busca el ID en la columna izquierda y copia el "membrete" en pantalla.
- Si una fuente nueva no aparece, añádela aquí antes de grabar — así nunca improvisas la cita.
- Para datos derivados (cálculos propios, ratios) usa siempre el ID `OCRE-CALC` con la fórmula en pie de página del informe.

## Cómo añadir un membrete nuevo

1. Localiza la fuente primaria (no segundas referencias).
2. Define un ID corto en MAYÚSCULAS con guiones: ORGANIZACIÓN-TEMA-AÑO.
3. Escribe el membrete en una línea con el formato `*fuente · serie/informe · año*`.
4. Pega URL primaria.
5. Anota qué datos concretos vendrán de esa fuente en "Notas".
